# IPScope — IP Address Intelligence Tool

IPScope is an IP lookup interface that validates IPv4 and IPv6 formats and presents network-related information in a dashboard.

## Features

- IPv4 and IPv6 format validation
- Interactive IP lookup dashboard
- Sample profiles for demonstration
- Responsive layout and dark/light theme

## Tech Stack

- HTML, CSS, JavaScript

## Getting Started

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Project Status and Limitations

This demo does not perform live geolocation, ISP/ASN lookup, proxy detection, or threat-intelligence checks. A trusted API and secure backend are required for live results.
