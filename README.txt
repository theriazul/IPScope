IPScope — IP Address Intelligence Tool

Files: index.html, style.css, script.js

Run: Extract the ZIP and open index.html in a browser, or use VS Code Live Server.

Important: This is a front-end demo. It validates IPv4/IPv6 formatting and shows illustrative sample profiles for selected demo IPs. It does not perform live geolocation, ISP/ASN lookup, proxy detection, or threat-intelligence checks. Connect a trusted API/backend to provide live results; do not expose private API keys in browser JavaScript.
